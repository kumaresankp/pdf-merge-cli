# PDF Toolkit

A simple command-line tool for merging PDF files.

## Installation

Install globally:

```bash
npm install -g pdf-joiner-kit

Or use with npx:

```bash
npx pdf-joiner-kit
```

## Usage

Merge multiple PDF files:

```bash
pdf-joiner-kit merge file1.pdf file2.pdf -o merged.pdf
```

### Example

```bash
pdf-joiner-kit merge document1.pdf document2.pdf -o final.pdf
```

## Options

```text
-o, --output    Output PDF filename
-h, --help      Show help
```

## Requirements

- Node.js 18+
- npm
